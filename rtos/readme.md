# RTOS под MS DOS 16bit

## Prerequisites

1. cmake (>=3.22)
2. docker
3. DOS BOX (для проверки)

## Build

```bash
./build_w_docker.sh
```

В корне проекта создастся папка build со всей шелухой от cmake, в том числе и библиотекой

## Usage

Несмотря на то, что это kernel мы вроде должны его использовать по сути как обычную библиотеку, при этом пытаться вручную эмулировать как оно должно работать.
